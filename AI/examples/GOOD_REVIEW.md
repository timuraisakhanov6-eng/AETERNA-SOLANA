# Canonical Documents Consulted

List every canonical document used during the review.

---

# Completed Work

Summarize the completed implementation or completed changes being reviewed.

# Findings

List confirmed findings.

Separate facts from recommendations.

---

# Review Results

Summarize the outcome of the review.

Clearly state whether the reviewed work satisfies the applicable canonical requirements.

---

# Protocol Compliance

State whether protocol integrity is preserved.

Identify any confirmed protocol violations.

---

# Security

Summarize security observations.

---

# Documentation

Summarize documentation consistency.

---

# Affected Files

List the implementation files affected by the review.

If no implementation files were reviewed, explicitly state:

None.

---

# Protocol Rules Involved

List the protocol rules or canonical requirements that governed the review.

---

# Recommended Corrective Actions

List only confirmed corrective actions.

Do not include speculative improvements.

---

# Remaining Limitations

Describe any remaining limitations or unresolved issues.

If none exist, explicitly state:

None.

---

# Recommended Next Steps

Recommend only the immediate next engineering action.

---

# Final Assessment

State whether the reviewed work is acceptable.

Explain any remaining issues.

Clearly distinguish confirmed findings from recommendations.
