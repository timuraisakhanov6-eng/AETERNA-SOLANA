# AETERNA Implementation Checklist

Version: 1.0

Status: Operational

---

Before implementation begins, verify:

□ Applicable canonical documents have been identified.

□ Canonical documentation has been read.

□ Applicable protocol rules are understood.

□ Existing implementation has been reviewed.

□ Required changes are clearly identified.

□ Implementation plan has been prepared.

□ Implementation risks have been identified.

□ Affected files have been identified.

□ No architectural redesign is required.

□ Protocol invariants will remain preserved.

---

During implementation:

□ Only approved scope is modified.

□ No undocumented behavior is introduced.

□ Authority boundaries remain unchanged.

□ Security properties remain unchanged.

□ Protocol terminology remains consistent.

---

After implementation:

□ Build succeeds.

□ Existing functionality remains intact.

□ Implementation matches canonical documentation.

□ Self-review completed.

□ Handoff information prepared.
